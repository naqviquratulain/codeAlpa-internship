# Visual Portfolio - Image Gallery

A responsive, accessible image gallery built from scratch using vanilla HTML, CSS, and JavaScript.

## Features
- **Responsive Layout**: Uses CSS Grid with `minmax()` and `auto-fill` to adapt to any screen size.
- **Category Filtering**: Filter images by Nature, City, or Animals with smooth transitions.
- **Custom Lightbox**: A fully custom modal with next/prev navigation and keyboard support.
- **Performance**: Uses `loading="lazy"` and preloads adjacent images to prevent flickering.
- **Accessibility (a11y)**: Includes ARIA roles, keyboard navigation (Tab, Enter, Arrows, Esc), and focus management.
- **Error Handling**: Automatically swaps broken image links with a clean placeholder.

## Technologies Used
- HTML5
- CSS3 (Grid, Flexbox, Variables, Animations)
- Vanilla JavaScript (ES6+, DOM Manipulation, State Management)
